# /review-post - 博客文章质量审查

## 规范入口

先读取 [文章审查与质量评分标准](../../../docs/review-checklist.md)，按其中的清单、门槛、六维评分、分档和报告格式执行。

目录、格式、引用和构建要求回读 [AGENTS.md](../../../AGENTS.md) 第 3、4、10、11 节。本技能只维护执行步骤，不复制清单和评分规则。

## 执行流程

1. 读取指定文章全文，识别目标读者、阅读收益和主类型，记录内容版本。
2. 按核心标准检查发布门槛，再逐项审查内容，记录位置和证据。
3. 核验关键引用、版本行为、代码和数字；访问或执行条件不足时明确标记待核验，不声称已验证。
4. 按核心标准计算各维度得分；证据不足时暂停总分和分档。
5. 使用核心标准的统一报告格式，优先给出最影响读者的问题和具体修改建议。
6. 用户要求修复时再修改文章，修改后复核受影响项并执行适用校验。

默认只审查，不修改或发布文章。评审报告按 `AGENTS.md` 的临时工作区规则保存。

## 使用示例

```text
/review-post source/_posts/AI/02-ai-agent-workflow-practice.md
```
