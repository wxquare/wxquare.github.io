正在维护的书籍

  • System Design Primer
  • AI Agent 工程实践

互联网系统设计

  • Designing Data-Intensive Applications（Martin Kleppmann）— 从可靠性、可扩展性到流处理，建立现代数据系统的判断框架。
  • Site Reliability Engineering（Betsy Beyer 等）— 用 SLO、错误预算和自动化运维理解生产系统的可靠性。
  • Clean Code（Robert C. Martin）— 从命名、函数和边界训练代码审美。
  • Domain-Driven Design（Eric Evans）— 用统一语言和限界上下文处理复杂业务。
  • Implementing Domain-Driven Design（Vaughn Vernon）— 将聚合、领域事件和仓储等概念落到工程实践。
  • Domain-Driven Design Quickly（Abel Avram）— 进入经典原著前的精炼导读。

AI 与 Agent

  • 深入理解 AI Agent：设计原理与工程实践（李博杰）— 覆盖上下文工程、记忆、知识库、工具、Coding Agent 和评估的系统实践。
  • AI Engineering（Chip Huyen）— 从模型选择、提示、RAG 到推理优化，讨论生成式 AI 的生产化。
  • Hands-On Large Language Models（Jay Alammar、Maarten Grootendorst）— 从 Transformer 到微调、RAG 与生成应用，是理解 LLM 实践的高密度入门书。
  • Build a Large Language Model (From Scratch)（Sebastian Raschka）— 从数据准备到预训练和微调，亲手走完 LLM 的关键实现环节。
  • Deep Learning（Ian Goodfellow、Yoshua Bengio、Aaron Courville）— 深度学习理论与方法的经典基础，帮助理解今天大模型技术的来处。
  • Designing Machine Learning Systems（Chip Huyen）— 从数据、评估到部署和监控，理解完整机器学习系统。

思维、商业与人文

  • Influence（Robert B. Cialdini）— 理解互惠、社会认同和稀缺等影响机制。
  • Zero to One（Peter Thiel、Blake Masters）— 用长期思考与差异化视角反思产品和创业。
  • Sapiens（Yuval Noah Harari）— 从宏观历史重新理解协作、制度与技术。
  • The Three-Body Problem（刘慈欣）— 在科学想象与文明尺度之间转换视角。
  • Thinking, Fast and Slow（Daniel Kahneman）— 理解直觉与理性如何共同塑造判断，适合反思决策中的系统性偏差。
  • Factfulness（Hans Rosling、Ola Rosling、Anna Rosling Rönnlund）— 用数据校正直觉，训练面对复杂世界时更稳健的事实判断。
