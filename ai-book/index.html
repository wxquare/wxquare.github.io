AI Engineering：大模型与智能体系统工程

书籍介绍

欢迎阅读《AI Engineering：大模型与智能体系统工程》。

这不是一本只介绍工具用法的书，而是一套面向软件工程师与架构师的 AI Engineering 知识体系。它关注一个更长期的问题：如何理解模型能力，如何稳定地生产和交付模型能力，以及如何把这些能力构建成可验证、可治理的应用系统。

全书沿着“理解模型能力 → 生产与交付能力 → 构建应用系统 → 评估与持续改进”的工程主线展开，覆盖大模型原理与算法、基础设施、Agent 系统、应用实战和前沿研究。Agent 是重要的应用系统形态，但不代表全书的全部范围。

全书工程主线图

本书按“大模型原理与算法 → 大模型基础设施 → Agent 系统工程 → Agent 应用与实战 → 前沿研究与工程展望”五部分展开。主线不是“学一堆工具名”，而是先理解模型能力如何形成，再理解模型如何被训练、部署、评估和治理，之后把模型放进可约束、可验证的应用与 Agent 运行环境，最后用真实案例和研究专题判断下一步能力边界。

本书解决什么问题

AI 工程实践里最容易踩的坑，不只是模型输出不稳定，也包括训练、推理、数据、评估和应用之间缺少清晰边界。我们把不清楚的意图、不完整的上下文、没有边界的工具和没有验证回路的流程交给模型，结果往往是第一版看起来很聪明，后续版本不断补洞并引入新问题。

本书的主线是把从模型能力到应用交付的过程，逐步收敛成可复用、可审查、可验证、可治理的工程系统。

读完之后，你应该能够回答六类问题：

  • 模型边界：LLM 擅长什么、不擅长什么，这些边界如何影响系统设计？
  • 能力交付：如何设计训练、推理、数据和评估基础设施，让模型能力稳定、经济地交付？
  • 任务协议：如何通过 Prompt、结构化输出和 Context 降低任务歧义与输出漂移？
  • 系统落地：如何通过 Harness、工具、知识、记忆和工作流构建 Agent Runtime？
  • 生产治理：如何评估、监控、调试、回滚并持续优化一个 Agent 系统？
  • 现实应用：如何把大模型与 Agent 用到编程、告警处理、企业知识、长期助手和研究任务中？

适合谁读

本书主要面向已经参与过真实软件项目的读者，包括后端工程师、AI 应用工程师、技术负责人，以及正在把 AI 编程或 Agent 系统引入团队流程的人。

你不需要是大模型研究员，但最好具备以下基础：

  • 能读懂一种主流编程语言的代码示例；
  • 理解 API、数据库、测试、日志、部署、权限等基本工程概念；
  • 对 LLM、RAG、Agent、MCP、Evals 等术语有初步印象，遇到细节时愿意回查。

如果你刚开始接触 AI 工程，建议按章节顺序建立基础；如果你已经在团队里落地 Agent，则可以直接从第三部分的 Agent 架构、工具、知识系统和生产治理部分切入；如果你负责平台建设，则可以优先阅读第二部分。

内容结构

第一部分：大模型原理与算法

这一部分建立全书的模型基础：理解 LLM 的能力边界、训练与推理机制，以及模型能力如何影响系统设计。它回答“模型能做什么、不能做什么、工程上为什么不能把模型当成万能组件”。

章章节一句话概述
第1章从 Transformer 到 Agent：模型结构如何影响系统能力从 token、Embedding 和 Transformer 出发，建立理解大模型算法与能力边界的基础。
第2章预训练：能力的来源解释预训练数据、目标函数、规模定律和模型能力形成之间的关系。
第3章后训练：行为的塑形介绍 SFT、RLHF、DPO、RLAIF 和安全对齐如何改变模型行为。
第4章推理期扩展讨论采样、推理预算、验证和生成算法如何影响模型输出。
第5章模型适配与能力扩展介绍参数高效微调、模型压缩和多模态模型算法。
第6章具身智能与 Physical AI介绍世界模型与具身智能的关系，理解“会说”如何走向“会做”。

第二部分：大模型基础设施

这一部分把算法模型放进真实系统，覆盖资源模型、训练、推理、数据评估、可靠性与治理。它回答“模型如何稳定训练、低延迟服务、持续评估，并在故障、成本和安全约束下长期运行”。

章章节一句话概述
第7章AI Infra 全景建立从算法结果到可运行平台的资源、生命周期和验收边界。
第8章训练平台与数据管线说明数据供给、并行训练、通信、恢复和训练制品如何形成闭环。
第9章推理服务与资源调度解释在线推理的请求调度、KV 管理、模型并行、容量和发布。
第10章评估与反馈闭环建立数据版本、评估、线上反馈和质量门禁的证据链。
第11章生产运营与治理控制连接 SLO、观测、成本、安全、供应链、发布和灾备。

第三部分：Agent 系统工程

这一部分讨论如何把大模型组装为真正可运行、可恢复、可治理的 Agent 系统。基础设施章节关注平台如何提供运行能力；本部分关注任务协议、上下文、Harness、模型协议、工具、知识、记忆、编排和行动控制如何共同形成应用级 Runtime。

章章节一句话概述
第12章LLM API 协议：模型能力如何被系统消费把模型接口当成系统契约来设计，而不是只看一次调用是否成功。
第13章Agent 的上下文工程：从任务协议到知识与记忆统一任务协议、知识检索、长期记忆、上下文装配、压缩与评估，建立每轮决策的信息供给链。
第14章知识检索与 RAG：从文档到可引用证据摄取、表示、索引、混合召回、多跳检索、证据与评估。
第15章Agent Runtime：架构、执行编排与可靠性工程根据任务类型选择和加载能力，调用外围工具系统，消费结果并处理等待、重试、审批与恢复。
第16章Agent 工具系统工程：Skills、Tools、MCP 与 Connectors从能力提供方构建工具契约与注册、Skills、MCP、Connectors、授权和沙箱。
第17章Agent 治理与调优：从质量闭环到分层落地把评估、护栏、观测与发布连成闭环，分层调优 Runtime、Skill、MCP、上下文与成本。

第四部分：Agent 应用与实战

这一部分将前面三部分的能力放到现实工作中：先拆解成熟产品，再落到企业和个人任务。它关心的是“如何用大模型与 Agent 完成一项可交付、可验证、可治理的真实工作”。

章章节一句话概述
第18章成熟 Coding Agent 内部实现：Codex CLI、Claude Code 与 OpenCode先建立共通执行闭环，再从公开源码和官方文档比较三种产品的实现边界。
第19章Pi Agent 架构解析：终端原生 Coding Agent Runtime、扩展系统与上下文工程分析一个终端原生 Coding Agent 如何组织运行时、扩展和上下文。
第20章OpenClaw 架构解析：个人 AI 助手的 Gateway、Runtime 与工具生态讲述个人 AI 助手如何通过 Gateway、Runtime 和工具生态协同工作。
第21章Hermes Agent 架构解析：长期运行、自我进化与多入口 Agent Runtime通过记忆、Skill、多入口和版本化源码理解长期运行；教学扩展与已核验能力分别说明。

第五部分：前沿研究与工程展望

这一部分讨论工程实践之外仍在快速演化的前沿问题。它不局限于 Research Agent，后续可扩展到多模态、具身智能、长期学习和世界模型等专题。

章章节一句话概述
第22章AI 智能体研究现状、工程瓶颈与未来理想能力架构报告从研究和工程两条线梳理智能体的现状、瓶颈与未来方向。

贯穿案例与练习的阅读方式

全书包含五部分、21 个公开章节；第四部分以成熟 Coding Agent 内部实现为案例，第五部分承接前沿研究。两个教学案例分别检验不同责任边界：

案例先建立机制再看应用重点核对
Coding Agent上下文工程、外围工具系统成熟 Coding Agent 的实现与 Harness代码版本、工作区、工具权限、候选完成与独立Verifier
Hermes 长期助手Runtime 状态、记忆生命周期、Runtime 编排Hermes 贯穿简报Session、Memory、缓存与特定投递 ledger 分别取证；通用业务 Outbox、Checkpoint、幂等和补偿是另行标明的教学扩展

章节包含原理推导、文档核验、教学轨迹与实验设计，验收层次分别标明。模型基础、后训练、模型适配、训练平台与推理服务的练习卡可从附录B进入；卡片完成不代表已经提供完整可运行代码、GPU测量或生产验证。选型先查附录C的版本和未知项，再回到章末原始来源。

与工程面试题库配合阅读

本书也可作为 AI 与 AI Agent 工程面试题库的原理与设计参考。题库保留每题的章节、小节链接、覆盖状态与缺口原因；本书按模型能力、基础设施和应用系统组织论证，不复制另一套逐题答案。定位以活动目录中的正文为准，归档材料、论文名或工具名本身不算覆盖。

“已覆盖”表示书中能找到主要原理和设计依据，可以组合相邻章节回答；它不表示已提供所有 SDK 的最新实现、个人项目经历或生产性能数据。“部分覆盖”会说明缺少的实现、实测或完整领域案例。阅读时应区分以下边界：

题目类型本书承担的内容需要另外完成的部分
模型、Agent、RAG 与生产治理机制、约束、选型、失败语义与验证方法将具体业务规模和环境代入，并补充真实证据
Attention、SFT Loss、校准与 CUDA 手写公式、输入输出、边界与练习验收卡完整代码、编译、执行与硬件测试；练习卡不等于参考实现
产品比较、Qdrant 性能及模型格式部署职责分层、版本化核验与受控比较方法同版本、同质量、同硬件的实测；不提供永久排名
客服、报告与漫剧扩展通用机制与明确标注的短案例或产物工作流完整领域平台及专用后端实现；短案例不等于端到端交付
K-means、CSV 读取与基础 MLP 手写仅保留索引聚类、FFN 等相关背景属于通用机器学习编程入门，不为题量扩张本书主线；保留题库原解答

书中案例与练习没有运行证据时，保持“教学设计”或“未实测”标识。外部接口、模型卡与硬件支持仍须核验具体版本；用户自己的经历不能用书稿案例代替。
