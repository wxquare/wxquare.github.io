附录A 术语与符号速查

本附录帮助定位正文中的定义。具体机制、来源与版本边界以表内责任章为准；同一个词在模型计算、任务运行和业务系统中可能指不同对象。

易混概念与责任边界

术语本书约定责任章
Context / Context Package当前一步装配给模型的指令、材料、约束与结果视图；受窗口、权限和版本限制Agent 的上下文工程
Memory / Memory Item跨步骤或会话保存的候选经验、偏好和摘要；有来源、作用域、失效与写入门控Agent 的上下文工程
State / Run、Step、Event权威执行事实、版本及事件；模型摘要和 Todo 只能引用，不能代替账本Agent Runtime
Evidence能支撑特定论点、可回读原位置且当前有权访问的版本化证据；不等于任意 chunkAgent 的上下文工程
Operation一次业务副作用的稳定身份与状态；超时后可为 unknown，不能直接按失败重做Agent Runtime
Checkpoint已提交状态与恢复位置；不回滚已经发生的外部副作用。训练 checkpoint 另含优化器、随机数和数据位置Agent Runtime、训练平台与数据管线
KV Cache前向计算中各层的键和值；用于复用历史计算，仍占用设备或分层存储资源推理服务与资源调度
Prefix / Prompt Cache复用兼容的前缀计算；自托管实现与商业 API 的命中、计费、保留语义分别核验推理服务与资源调度、Hermes Agent 系统
精确响应缓存 / 语义响应缓存前者匹配请求及其依赖版本，后者先召回相似候选再验证答案等价；两者都需授权、新鲜度和失效控制推理服务与资源调度
Tool Calling / Skill / MCP分别是结构化行动请求、可复用方法上下文、能力连接协议；实际执行、权限和审计由 Runtime 承担外部工具系统
MCP / A2AMCP 连接工具、资源和提示，具体协议版本以工具章的版本边界为准；A2A 按 v0.3.0 描述独立 Agent 的任务/消息/产物协作。自建 mailbox 不自动兼容 A2A第 16 章外部工具系统
Triton 语言 / Triton Inference Server前者用于编写 GPU 计算程序；后者负责模型服务与模型管理，二者不是同一层的软件训练平台与数据管线、推理服务与资源调度
Model Manifest / Eval Case前者绑定模型、模板、格式与执行兼容条件；后者绑定输入、预期、不变量和版本化评估配置AI Infra 全景、第 11 章评估与反馈闭环

模型计算符号

下表沿用模型结构及推理服务与资源调度的记账口径。其他章节可用局部符号，但须重新定义。

符号含义与单位
B、T、Sbatch 大小、当前查询长度、可见键/历史长度；不是字符数
D、L残差宽度、层数
H_q、H_kv、d_h查询头数、KV 头数、单头维度；GQA 不减少查询头数
s每元素字节数；量化还需计入 scale、布局、工作区等开销
logits / labels / loss mask预测分数、目标 token、有效监督位置；标签与预测错位只对齐一次
TTFT / TPOT首 token 时间 / 每输出 token 时间；是否包含排队、网络和重试须说明
prefill / decode处理输入序列 / 增量生成；两阶段的资源瓶颈和缓存收益不同
token / Context Windowtokenizer 产生的模型单位 / 模型及接口允许的输入输出边界；汉字与 token 无固定比例，预算用目标 tokenizer 与实际 usage
