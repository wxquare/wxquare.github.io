# 全书思考题与设计推演导向设计

## 背景与目标

《AI Agent 工程实践》是一部系统化书稿，不应以时间盒式阅读计划、面试准备或作品集包装作为读者入口。本次改造将全书统一调整为工程学习、独立思考和设计推演导向：保留已有技术问题、案例、参考答案和项目材料的价值，但移除“面试”“面试官”“候选人”“作品集”等求职语境。

目标是让读者把问题用于复盘、评审、方案设计和项目实践，而不是背诵应答话术。

## 范围

### README 与目录

- 删除 `books/ai-book/src/README.md` 的“阅读路径”整节，包括“快速上手：2-3 天”“系统学习：1-2 周”“项目驱动：随用随查”及相关时间承诺。
- 将 README 中“按快速上手路径”“面试表达材料”“面试或作品集”等措辞替换为顺序阅读、按需查阅、思考题或项目实践材料。
- 将附录说明改为：术语、参考资料、工具、系统设计思考题和项目实践材料。
- 更新 `books/ai-book/src/SUMMARY.md` 的附录 D、E 标题和目标路径，使导航不再出现“面试”或“作品集”。

### 正文章节

全书所有正文 Markdown 中的“面试表达”“面试加分表达”“面试和作品集表达”“准备面试”等内容，统一按语义改写：

| 当前语境 | 新语境 |
| --- | --- |
| 面试表达 | 思考题 / 设计推演 |
| 面试加分表达 | 进阶设计推演 |
| 面试官问…… | 评审或复盘时，可追问…… |
| 候选人回答…… | 设计者需要说明…… |
| 面试信号 | 工程信号 / 评审关注点 |
| 准备面试 | 用于方案复盘或设计评审 |
| 作品集 | 项目实践 / 项目材料 |

改写不删除技术结论、架构取舍、失败案例、题目、答案或代码；只调整其引导语和标题，使其成为可用于自测和团队讨论的内容。

## 术语与边界

- “思考题”用于让读者独立推导概念、取舍和失败模式。
- “设计推演”用于有上下文的架构、指标、风险和发布决策练习。
- “项目实践”用于将书中方法落在可运行或可审阅的项目材料上。
- 不改变与真实招聘市场、论文标题、外部链接标题相关的原始引用；如果某一外部来源名称本身包含 `Interview`，可保留 URL 与原名，但不得将其作为本书的导向性措辞。
- 不直接编辑 `books/ai-book/book/`、`public/` 或 `.deploy_git/`。
