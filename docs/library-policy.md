# 公开参考资料库治理规则

`source/library/` 是本仓库公开第三方参考资料的唯一活动入口。资料公开可读并不自动代表本仓库可以重新托管；不能确认再分发边界时，只记录原始链接。

## 允许的资料类型

默认只接收以下三类公开技术资料：

- books：公开书籍、手册或长篇技术参考资料
- papers：公开论文、技术报告或标准文档
- slides：公开会议、课程或技术分享的演示文稿

每份资料只进入一个分类。博客文章、个人文件、内部材料和实验源码不属于公开参考资料库。

## 必填元数据

每条索引记录必须包含：

- 标题
- 作者或机构
- 类型：book、paper 或 slide
- 主题
- 原始来源 URL
- 本地文件路径或“仅外链”
- 再分发说明
- 加入日期

缺少任一元数据字段时，不得加入索引。无法确认重新托管依据时，将本地路径记为“仅外链”，并在再分发说明中记录原因。

## 再分发边界

只有在来源公开、内容适合公开保存，并且有足够依据确认可以重新托管时，才允许把文件副本放入 `source/library/`。仅能确认公开访问、但无法确认再分发授权时，索引只保留原始 URL、主题和必要说明，不上传副本。

以下内容禁止以本地副本进入资料库：

- 个人资料或可识别个人的信息
- 公司内部、客户或未公开工作材料
- 包含密码、Token、API Key、私钥或其他凭证的内容
- 来源、授权或再分发边界不明确的内容

单个二进制文件超过 10 MiB 时，默认改为“仅外链”。只有用户单独批准存储方案后，才可以本地托管。

## 单一事实源

- 公开活动资料只在 `source/library/` 维护；其他仓库不保留并行维护的活动副本。
- 仅外链条目以原始来源为事实源，本仓库不复制其载荷。
- 不把同一资料复制到多个分类；需要从文章引用时，链接到资料库条目或原始来源。
- 迁移源只有在公开提交、构建和哈希验证完成并获得删除批准后，才可以移除。
